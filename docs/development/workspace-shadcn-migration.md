# 主工作区与会话的 shadcn 组件迁移

主工作区和会话界面复用 `packages/ui/src/components/ui` 已有的 shadcn 组件；组件按 `DESIGN.md` 使用项目语义色和字号。桌面、Web 与窄屏共用业务交互，不能因组件替换改变会话、草稿、工作区或远程连接的状态所有者。

## 当前迁移范围

- 新建任务入口使用共享 Button，保留快捷键提示、禁用语义、遥测与测试标识。
- 会话工作区 Hook 待审核提示的操作使用共享 Button，保留审核命令、忽略状态与测试标识。
- 跨工作区会话归属使用共享 Badge，保留路径提示、远程标识与测试标识。
- 聊天输入框聚焦时保留输入背景反馈，外层边框不切换为蓝色焦点色；全局键盘焦点描边不应用于 Lexical 可编辑区，外层中性边框仍标识输入区域。

## 验收和维护

按钮应支持鼠标和键盘，禁用时不能触发；待审核提示可审核或忽略，忽略仍按 session 和 bundle 生效；跨工作区徽标显示现有名称及远程状态。检查浅色、深色、窄屏和长文本；后续迁移其他界面时继续复用共享组件，保持各区域原有状态与事件路径，逐项补充验收场景。
