# 协作工作台与智能体入口

本规范约束共享桌面与 Web 工作台的协作入口及草稿首页。视觉参考 `frakio-work` 的侧栏、居中问候、输入卡片和卡片下方项目选择；使用 ZCode 现有主题、组件和品牌，不引入参考项目的源码或标识。

## 状态与边界

```text
工作区 identity/path → useSubagents → 已启用的 Agent 目录 → @ 候选
用户选择 → 编辑器草稿中的 @名称 → 既有提交命令 → CLI 会话及子 Agent 事件
                                                   ├→ Desktop continuous 投影
                                                   └→ Web replayable 投影
子 Agent 行（可见时）→ 复用当前 Host 的 SessionDataLayer 租约 → 子会话快照/增量 → 消息预览
子 Agent → SendMessage → 父运行时同一分支的任务目录及消息额度 → 活跃同伴的 CommandInbox
                                                                     ├→ Desktop continuous
                                                                     └→ Web replayable
```

Agent 配置和模型仍由现有子 Agent 服务、模型供应商及运行时管理；编辑器只持有未提交草稿，不自行发起模型请求、创建队列或持久化 Agent 状态。远程目录沿用现有 `workspaceIdentity` 和 remote session 路由，连接不可用时不使用其他工作区的列表。选择 Agent 只插入既有的 `@名称` 文本，与 `/` 菜单语义相同：主 Agent 根据任务决定调用，不能承诺直接切换说话者或强制运行。子 Agent 的执行、失败、权限、恢复和结果仍由现有运行时与投影负责。

主模型可见的 Agent 工具说明将用户消息中的 `@名称` 与工具目录中的智能体名称关联，并说明只有任务意图要求委派时才使用相应 `subagent_type`；名称本身不授权执行，也不影响工具权限。该说明属于现有工具描述，不创建新的隐藏消息或持久化状态；恢复会话时仍由当前运行时的工具目录提供。

同一父会话的运行中智能体可通过现有 `SendMessage` 工具发送同伴消息：支持唯一的智能体名称或实例 ID，名称冲突时明确失败。父运行时的任务注册表是参与者和生命周期的唯一所有者，校验发件人、收件人、父会话、当前分支和活动消息接收端；不能给自己、其他会话、旧分支或已停止的智能体投递，也不能通过同伴消息创建或恢复智能体。工具仍受智能体自身工具白名单、全局禁用规则和权限控制。父运行时为其生命周期内所有同伴消息设置共享上限，限制互相回复形成的循环；结束或重启后的运行时重新建立额度，已结束的子任务不会因此重启。

同伴消息直接进入目标现有活动轮次的 guide 准入；父运行时按发送者和工具调用 ID 对本运行时的重复调用去重，保留发送者实例身份并使用既有同伴消息权限提示。准入失败明确返回失败，不另建 Renderer 队列、后台续跑或虚假的成功回执。接收端按现有队列消费和持久化规则处理；进程退出后的重复投递及未消费消息不承诺恢复。Desktop 与 Web 只订阅各自已有会话投影，同一运行时负责路由。

## 界面和验收

- `@` 面板及输入框的添加菜单包含已启用 Agent，按既有名称去重规则优先工作区配置，并显示已配置的模型；`@` 支持名称、描述和模型搜索，保留文件、插件、会话和画板入口。`/`、`#`、`$` 的现有行为不变。
- 鼠标或键盘选中 Agent 后插入相同的 `@名称` mention，不立即发送；禁用项不出现，加载与错误由现有目录状态展示。
- 草稿首页以居中问候与输入卡片为视觉中心，工作区选择位于卡片下方；已有会话及手机宽度继续使用同一提交路径。沿用现有浅深主题、字号和键盘焦点约束。
- 智能体设置按来源分组，以响应式卡片呈现名称、说明、模型、工具和可用操作；编辑、删除、启停及内置模型覆盖仍调用现有设置服务。窄屏单列，操作不会触发卡片的编辑动作。
- 主对话中的 Agent 行从同一 Host 的子会话投影展示最新真实 assistant 消息，并可打开完整子会话。只消费可见的流式或已完成正文；缺少子会话、开始时间、消息或订阅失败时不伪造内容。子 Agent 恢复运行时只接受创建时间晚于本次启动时间的消息，避免把上一轮回复当成本轮回复。
- 预览只在运行中或成功状态订阅；卡片卸载、子会话改变或终态变化时释放引用。子会话仍是消息唯一所有者，复用同一个 `SessionDataLayer` 的引用计数和订阅恢复；Desktop 的 continuous 与 Web 的 replayable 语义不变。预览不修改、重新发送或持久化消息，不改变主 Agent 的结果汇总。
- 单元测试覆盖目录去重、过滤和触发器分组；交互验证覆盖 `@` 选中、草稿保存、提交及窄屏。模型运行应使用隔离的测试端口验证，不使用真实密钥。
- 模型选择验证覆盖智能体显式配置、父模型继承和供应商不可用的失败行为；显式选择失败不能静默回退到其他模型。

## 后续能力边界

当前子运行时在 `apps/zcode-cli/packages/core/src/runtime/methods/subagent.ts` 中禁用继续派生子 Agent，通过 `coordinatorResponsePort` 向父运行时返回消息；父会话投影提供子 Agent 生命周期和工具摘要，界面预览读取子会话投影中的正文。会话跟随和直接由用户向指定智能体开新轮次的群聊路由尚未提供，不得把 UI 中的 `@名称` 描述成确定性直接路由。
