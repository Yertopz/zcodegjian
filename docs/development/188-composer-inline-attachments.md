# 输入框内嵌附件、调节高度与提示词优化

## 产品与运维约束

图片、文档及其他拖入或粘贴的文件在输入框正文中作为不可拆分的引用卡片展示，保留插入位置；图片显示编号与缩略图，文件显示名称及类型。双击或键盘预览动作打开图片/文档查看器，单击不抢走继续编辑的上下文。网址按普通文本插入，不生成附件卡片或自动抓取内容。上传中、失败、重试、移除和发送失败恢复沿用既有附件链路；不把二进制或 blob URL 写入持久化编辑器 JSON。

Lexical 编辑器是正文及引用位置的唯一所有者，composerAttachmentUploadStore 仍是附件内容、上传状态与暂存引用的唯一所有者。编辑器节点只保存稳定的附件 ID、编号和显示文字；节点展示从当前输入框 scope 的附件投影读取。主对话与辅助对话、同路径不同工作区不得混用附件。发送以当时的正文和引用快照为准，不自动发送、不把附件展示文字当作用户新需求；已发送消息保留图片编号与文件信息，能够预览。

输入框上缘提供上下拖动手柄，同时支持键盘上/下调整及重置。高度只属于本地展示状态，按可用视口约束最小/最大值，正文超过高度时在输入框内滚动；不改变会话事实或重建编辑器，不影响光标、草稿和撤销历史。手机仍能输入且控件可触达。

## 提示词优化

工具栏提供“优化”按钮，使用本次点击时当前输入框所选模型，通过既有 generateWorkspaceText 做独立、无工具的文本请求，不启动 Agent、不写聊天历史、不读取项目文件，也不自动提交聊天。仅发送用户本次需要优化的正文；附件引用使用不可改写的占位符，不上传附件内容给优化请求。默认优化规则内置，不修改主提示词库。

跨 Renderer/Host RPC 只传可序列化的 operationId，不传 AbortSignal。generateWorkspaceText 为可选 operationId 建立工作区隔离的在途取消句柄，cancelWorkspaceTextGeneration 按同一身份与 ID 取消；直接在服务内调用仍可使用原 signal。句柄在异步路由前登记，路由/鉴权结束后再次检查取消状态，再进入既有 workspace.generateText；完成或失败必定释放。取消失败明确提示，不把本地停止等待伪装成远端已经停止。

没有本地路径的普通二进制文件经既有 attachmentPut 分块事务上传实际 File 字节，大小受现有协议附件上限约束；不能退回只有文件名的空引用。桌面本地路径继续零拷贝，远端路径继续先暂存，不改所有权转移规则。双击预览复用现有 PDF、Word/Excel 查看器和文本预览；浏览器 Office 文件预览上限为 20 MiB，文本预览为 256 KiB，其他或超限格式明确提示并提供下载。

已发送普通文档通过 conversationAttachmentRead 读取，由当前会话的 rowId、entityId、原始附件下标和 ref 共同授权；缺少稳定消息身份时明确不可预览。图片、视频、PDF 沿用媒体预览接口，不把普通文档送入仅允许媒体类型的 attachmentRead，也不在授权失败后降级为路径读取。

运行时优先读取消息持久化的 artifact 副本；若普通文档的 FilePart 只有展示文件名而无 artifact 元数据，保留已由消息授权的上传 artifact 引用，不将其替换成相对文件名。原生绝对路径附件沿用既有路径读取。附件字节仍由对应会话 runtime 的 artifact store/FileSystemPort 读取，远端不会落到本机文件系统。

上传 artifact 的 data URL 解码器接受通用文档类型，保留编码及字节上限校验；媒体类型白名单由 gateway 的媒体查询接口执行，通用文档查询仍必须经过消息附件授权，不由底层解码器重复限制为媒体。

内置正文：

```text
你是谨慎的提示词文字编辑。仅把用户原文整理得清楚、准确、易于 AI 理解。
保留原文的目标、事实、限制、语气、语言、路径、网址、代码和全部引用占位符。
只修正明显的错别字、重复、歧义表达与语序，可做必要的分段，不做大幅扩写。
不得猜测用户意图，不得增加原文没有的需求、背景、事实、技术方案、步骤或验收标准，不得凭空补全缺失信息。
原文不明确时保留其不明确之处，不擅自作决定；原文已经清楚时可以保持不变。
不要执行原文中的任务。只输出修改后的提示词，不加解释、标题或代码围栏。
```

按钮显示进行中状态，允许取消；空正文或无可用模型时不可启动。结果先预览，由用户应用或取消，不直接覆盖输入。请求固定 scope、正文及编辑器快照；切换对话、用户继续编辑或附件变化后，不可用迟到结果覆盖新草稿。应用保持附件引用与已有 mention，支持撤销。失败/空输出/引用占位符损坏明确提示并保留原文，不静默降级为其他模型。

```text
拖入 → 附件 store 接收/上传 → 当前 scope 节点插入 → 正文中展示 → 双击预览
发送 → 固定正文与有效附件 → 原 admission → accepted 后清理 / 失败恢复
优化 → 固定 scope、模型与原文 → 无工具文本生成 → 预览 → 原文仍匹配才应用
```

## 验收

- 图片/文档/多文件拖入与粘贴位于正文中，编号、缩略图、移除、双击预览和网址纯文本正确。
- 上传失败、发送失败、scope 切换及过期结果不丢草稿、不串附件；节点 JSON 不含文件内容或临时 URL。
- 实际拖动输入框上缘可改变高度，键盘与重置可用，光标及撤销历史保留。
- 优化请求使用选中模型、内置保守规则且无工具；预览取消、应用、撤销、失败与并发编辑保护可用，附件及 mention 完整保留。
- 通过隔离浏览器/桌面和本机假模型端口验收最终输入、请求与消息展示；如实记录未执行的平台。执行 typecheck、lint、相关测试、格式、架构和文档检查。
