# 3.16.3-ce.1 定制升级约束

- 升级以 CE 发布标签 v3.16.3-ce.1 为基线，保留本地浏览器控制台、SSH 服务工作台、主提示词和界面定制。
- 运行时设置仍由各自 Host 的 settingService 持有：本机 Host 下发工具搜索与附加目录，桌面附着远端时由远端 Host 下发；主提示词保持原有 main-agent-prompts 范围的本地设置解析。
- 主提示词只在既有 main-agent-prompts 请求范围读取；附加目录在现有 runtime-materialization 路径解析，工具搜索使用既有模式及缺省行为。协议字段均保持可选，兼容旧 Host。
- 浏览器控制台按实例隔离权限与网络策略；SSH 高风险操作继续由已有审批队列准入。升级不改变它们的用户授权或持久化所有者。
- 必须检查新旧设置、远端连接、UI 主题和焦点、新建会话与已有定制；验收未完成的能力明确报告，不把构建产物当作最终验证。

- 设计令牌基线使用跨平台统一的正斜线路径；Windows 与其他平台应对同一文件应用相同限制。
